# Project preferences

- Choose free services and tools by default. Do not enroll in paid services, start billable trials, or add a paid dependency without explicit user approval.
- Windows distribution is pursuing the free SignPath Foundation program. Approval and integration are pending; do not claim Foxsocket is enrolled or signed.
- Do not stop development while publisher signing is pending. Support explicit unsigned development builds and label their limitations. Preserve signature verification requirements for trusted public distribution.
- Use isolated app profiles for development. Do not call them a clean OS installation: installed runtimes and model caches remain shared. Never change Windows security settings automatically.
- Keep LENOVO-START-HERE.md and the active PR aligned with the actual build/test status so both PCs share one handoff.
